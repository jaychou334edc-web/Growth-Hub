# Growth Hub 软件需求规格说明书（SRS）

（V1.1 Final）

------

# 一、项目定位

Growth Hub（成长自律中心）是一款面向大学生和知识工作者的成长管理应用。

核心目标：

帮助用户形成：

```text
任务
 ↓
专注
 ↓
记录
 ↓
统计
 ↓
反馈
```

的成长闭环。

------

项目不是：

```text
Todo List
日历
单纯打卡软件
```

而是：

```text
任务管理
+
专注系统
+
成长统计平台
```

------

# 二、核心理念

Growth Hub 的核心实体不是任务。

而是：

```text
FocusRecord
（专注记录）
```

因为所有成长行为最终都能转化为：

```text
投入了多少专注时间
```

例如：

```text
数学学习
英语学习
阅读
写代码
健身
```

最终都会产生：

```text
FocusRecord
```

因此：

所有统计必须基于 FocusRecord 生成。

禁止维护冗余统计字段。

------

# 三、用户画像

主要用户：

大学生

考研学生

长期阅读者

需要专注训练的人群

# 四、功能模块

------

## 模块1：首页 Home

首页是高频入口。

展示：

```text
今日专注时长

本周专注时长

最近任务

最近倒数日

励志语录

近30天活跃率

最近获得成就

最近一次专注记录
```

------

首页必须包含：

```text
开始专注
```

大按钮。

用户路径：

```text
首页

↓

开始专注

↓

选择任务

↓

选择模式

↓

开始
```

模式：

```text
倒计时

正计时
```

------

## 模块2：分类管理 Category

作用：

类似文件夹。

仅用于组织任务。

不参与统计。

功能：

```text
新增分类

编辑分类

查看分类

归档分类
```

------

示例：

```text
考研

阅读

健身

工作
```

------

## 模块3：任务管理 Task

任务是专注的载体。

功能：

```text
新增任务

编辑任务

完成任务

归档任务

查看详情
```

------

任务支持：

```text
分类

标签

状态
```

------

状态：

```text
ACTIVE

COMPLETED

ARCHIVED
```

------

说明：

系统禁止物理删除任务。

删除操作统一转为：

```text
ARCHIVED
```

------

任务详情页显示：

```text
累计专注时长

专注次数

平均专注时长

最近专注时间

标签

历史记录
```

------

## 模块4：标签系统 Tag

功能：

```text
新增标签

编辑标签

删除标签

任务关联标签
```

------

示例：

```text
高优先级

英语

真题

强化阶段

阅读
```

------

标签参与：

```text
筛选

统计
```

------

## 模块5：专注中心 Focus

系统核心模块。

------

支持两种模式：

### 倒计时模式

预设：

```text
25分钟

45分钟

60分钟

90分钟
```

支持：

```text
自定义时长
```

------

### 正计时模式

用户主动停止。

适用于：

```text
阅读

写代码

长时间学习
```

------

专注状态：

```text
IDLE

RUNNING

PAUSED

FINISHED

CANCELLED
```

------

说明：

CANCELLED：

```text
放弃专注
```

不会生成 FocusRecord。

------

结束专注后：

弹出：

```text
学习状态评价

专注备注
```

------

评价：

```text
GREAT

GOOD

NORMAL

BAD
```

------

允许跳过。

默认：

```text
NORMAL
```

------

备注可为空。

------

# 五、业务规则

------

规则1

统计永远包含：

```text
ACTIVE

COMPLETED

ARCHIVED
```

任务。

------

规则2

任务选择器仅显示：

```text
ACTIVE

COMPLETED
```

任务。

------

规则3

所有统计必须来自：

```text
FocusRecord
```

------

规则4

FocusRecord不可修改。

只能新增。

------

规则5

FocusRecord是系统唯一事实来源。
