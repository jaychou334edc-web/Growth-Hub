# 一、架构目标

Growth Hub 是一个：

```text
Local First
单机 Android 应用
```

系统特点：

```text
无账号系统

无云同步

无服务器

SQLite 本地存储

FocusRecord 为唯一事实来源
```

------

## 核心设计原则

### 原则1：FocusRecord 是 Single Source Of Truth

禁止维护：

```java
task.totalDuration

task.focusCount

category.totalDuration
```

这类冗余统计字段。

所有统计必须通过：

```text
FocusRecord
```

动态计算。

------

### 原则2：Task 只是专注载体

Growth Hub 本质上不是 Todo 软件。

Task 的作用：

```text
给 FocusRecord 提供归属
```

而不是：

```text
统计中心
```

------

### 原则3：所有统计包含归档任务

统计系统查询：

```text
ACTIVE

COMPLETED

ARCHIVED
```

全部任务。

------

任务选择器显示：

```text
ACTIVE

COMPLETED
```

任务。

------

### 原则4：不允许物理删除 Task

删除：

```text
ACTIVE
 ↓
ARCHIVED
```

保留所有历史数据。

------

# 六、数据库设计

------

## Category

```sql
CREATE TABLE category(
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    name TEXT NOT NULL,
    description TEXT,
    create_time INTEGER
);
```

------

## Task

状态改为整数枚举。

```sql
CREATE TABLE task(
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    category_id INTEGER,
    title TEXT NOT NULL,
    description TEXT,
    status INTEGER NOT NULL,
    create_time INTEGER,
    update_time INTEGER
);
```

------

状态定义：

```java
public static final int ACTIVE = 0;
public static final int COMPLETED = 1;
public static final int ARCHIVED = 2;
```

------

索引：

```sql
CREATE INDEX idx_task_category
ON task(category_id);
```

------

## Tag

```sql
CREATE TABLE tag(
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    name TEXT NOT NULL,
    create_time INTEGER
);
```

------

## TaskTag

```sql
CREATE TABLE task_tag(
    task_id INTEGER,
    tag_id INTEGER
);
```

------

唯一索引：

```sql
CREATE UNIQUE INDEX idx_task_tag
ON task_tag(task_id, tag_id);
```

避免重复绑定。

------

## FocusRecord

系统核心表。

```sql
CREATE TABLE focus_record(
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    task_id INTEGER,
    start_time INTEGER,
    end_time INTEGER,
    duration INTEGER,
    mode INTEGER,
    mood INTEGER,
    note TEXT,
    create_time INTEGER
);
```

------

mode

```java
COUNTDOWN = 0

COUNTUP = 1
```

------

mood

```java
GREAT = 0

GOOD = 1

NORMAL = 2

BAD = 3
```

------

索引：

```sql
CREATE INDEX idx_focus_task
ON focus_record(task_id);
CREATE INDEX idx_focus_start_time
ON focus_record(start_time);
```

------

## CountdownEvent

新增提醒配置。

```sql
CREATE TABLE countdown_event(
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    title TEXT,
    target_date INTEGER,
    description TEXT,
    remind_days_before INTEGER,
    create_time INTEGER
);
```

------

remind_days_before

```text
0

1

3

7
```

------

时间统一：

```text
SQLite保存Unix时间戳(ms)

展示时转换本地时区
```

------

## Quote

```sql
CREATE TABLE quote(
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    content TEXT,
    is_system INTEGER,
    create_time INTEGER
);
```

------

## Achievement

```sql
CREATE TABLE achievement(
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    title TEXT,
    description TEXT,
```

# 九、FocusService

V1.1重大修改：

采用：

```text
ForegroundService
```

------

原因：

Android 8+

后台Service限制。

------

启动流程：

```text
startService()

↓

startForeground()
```

必须在5秒内执行。

------

持续通知内容：

```text
正在专注

剩余时间

停止按钮
```

------

状态机：

```text
IDLE

RUNNING

PAUSED

FINISHED

CANCELLED
```

------

结束：

```text
生成FocusRecord
```

------

取消：

```text
不生成FocusRecord
```

# 十三、StatisticsEngine

独立引擎。

------

职责：

```text
日统计

周统计

月统计

排行榜

活跃率
```

------

活跃率规则：

```text
近30天

duration >= 60秒

记为活跃一天
```

------

计算：

```text
活跃天数

/

30
```

------

示例：

```text
28 / 30

=

93%
```

------

性能优化：

所有统计必须：

```sql
WHERE start_time >= ?
```

限制时间范围。

------

# 十四、AchievementEngine

独立引擎。

------

触发时机：

```text
FocusRecord插入成功
```

立即检查。

------

流程：

```text
Focus结束

↓

插入FocusRecord

↓

AchievementEngine.check()

↓

解锁成就

↓

发送通知
```

------

必须保证：

```text
幂等
```

即：

同一成就只能解锁一次。


# V1.1 最终架构核心

```text
Category
    │
    ▼
Task
    │
    ▼
FocusRecord
    │
    ▼
StatisticsEngine
    │
    ├── Home
    ├── History
    ├── Statistics
    └── Achievement

CountdownEvent

Quote

独立存在
```

最终原则：

```text
FocusRecord 是系统唯一事实来源

所有统计从 FocusRecord 计算

Task 不保存统计数据

归档任务不影响历史统计

ForegroundService 保证计时可靠运行
```
